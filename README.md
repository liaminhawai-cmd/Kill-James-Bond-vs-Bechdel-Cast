# Kill James Bond! vs The Bechdel Cast

Comparative discourse analysis of two feminist film-criticism podcasts across 13 matched film pairs.

**Start here, every session: [ANALYTIC_BRIEF.md](ANALYTIC_BRIEF.md)** — project definition, corpus inventory, hypothesis stack, methods rules. Then check [FINDINGS.md](FINDINGS.md), the running scoreboard and corrections log, updated after every essay.

```
ANALYTIC_BRIEF.md   read first, every session
FINDINGS.md         hypothesis scoreboard + corrections; update after EVERY essay
/transcripts        cleaned corpus (26 files; 2 off-corpus extras in /transcripts/extras)
/essays             01–13, one per matched pair, KJB-chronological order
/synthesis          written last, from FINDINGS.md
/tools              corpus cleaning script (podscripts scrape → cleaned transcript)
```
