# Synthesis III — Status economies, guests, and positionality

*Skeleton. The pragmatics-of-status throughline: covert vs overt prestige, guest management, and the identification axis (H6/H11). Gets its centrepiece from Point Break (Sarkeesian, essay 06).*

## Thesis (provisional)
The two shows run opposite **status economies**. BC: disclaim competence while displaying it (covert prestige), apology subroutine, cooperative repair, pedagogy addressed to an imagined newcomer. KJB: assert sincerity-as-bit while practising it, staged combat without real conflict, initiate-address. Guests are absorbed differently because the *imagined listener* differs, not because guests behave differently.

## Guest management (the controlled variable so far)
Every pair to date is guest-symmetric, and **neither show's register moves for the guest**:
- BC re-teaches the Bechdel test from scratch to network-insider guests who know it (theory-of-the-listener: the lesson is for the imagined newcomer, not the guest in the room).
- KJB issues a rank and absorbs the guest (Ocean's, The Rock, Casino Royale, Austin Powers — all pre-aligned peers).

## Centrepiece-in-waiting — the status inversion (Point Break, essay 06)

If borne out, this is the richest status-economy material in the book — and a confirmation-discipline test, since our pre-corpus in-chat Point Break analysis is on record.

## Positionality — the identification axis (H6/H11)
Strongest mirror so far (essay 03, Austin Powers): the *same two transphobic punch scenes* read outside-protectively (BC: "that was so upsetting") vs inside-the-blast-radius (KJB: "we've had it yelled at us out of cars"; "God's gift to bullies"). Position licenses different analytic permissions: KJB can complicate (Thunderball lift); BC, speaking from outside, must condemn plainly. Same verdict, opposite epistemic permissions.
- Queer-reading epistemics (H11): defer-from-outside (BC) vs assert-from-inside (KJB). **Essay 05 deposit (Atomic Blonde, the definitive H11 pair): REFINED to constitutive vs imported inside-ness.** KJB's inside-ness is constitutive — all three hosts read queerness from inside as the default voice (top/bottom legibility, bisexual lighting, "it's a bit gender for me"). BC SPLITS: the house register (Caitlin) teaches queerness to the imagined newcomer (bury-your-gays defined, bi-erasure as pedagogy = defer-outside), while the lived inside view is IMPORTED through the queer guest (Guerrero's first-person queer desire + the Bride-of-Chucky "queer death doesn't read as punishment because the writer was gay" argument, which is structurally KJB's move). The rotating guest chair is HOW BC's format accesses inside-ness without changing its register — same machine as theory-of-the-listener (H2) and the identification axis (H6).
- **Hard rule:** positionality is analysed at the level of stated public position and identification vector only — never via H15 / anyone's medical history.
