## How the transcripts are organized

Each transcript file follows this format:



NN - Episode Title.txt


Where:
- `NN` is the **episode sequence number**
- Lower numbers = **earlier episodes**
- Higher numbers = **later episodes**

When citing or discussing content, use:
- **Episode #** for ordering

and reappears in Episode 17…”

## Recommended analysis strategies

Useful ways to work with this corpus:

- Track recurring concepts across episodes (e.g. dominance, asymmetry, violence, ritual)
- Compare early vs late positions on the same idea
- Identify conceptual clusters rather than isolated arguments
- Note when descriptive biology shifts into normative claims

This is not a polished publication corpus; it is a **thinking corpus**.

## Transcript quality notes

- Transcripts were generated using **Whisper (GPU)**
- Speaker diarization is minimal
- Some technical or proper nouns may be misspelled
- Meaning is generally preserved even when wording is imperfect

Treat transcripts as **semantic records**, not verbatim quotations.
