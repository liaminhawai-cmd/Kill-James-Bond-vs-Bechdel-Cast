## Use discipline

- These are WRITTEN PROSE, not podcast transcripts. No cross-medium rate
  comparison with the KJB/BC counts is valid (prose hedging/profanity norms
  differ from speech). Within-pool comparison (prose vs prose, same genre)
  is valid and is what third_pole_counts.py produces.
- The pool tests the AFFECT-GRAMMAR layer of Q16 only. Nothing dialogic
  (status economies, guest management, conversational theory-of-listener)
  can be tested on monologue prose.
- n=3 conservative texts, one film. Proof-of-concept, not a corpus.
- Disposition is coded from each text's own discourse; venue is a prior,
  not a verdict.
- Quotation discipline and the H15 rule apply here exactly as everywhere.
